# CodeAlpha_Hangman

A simple text-based Hangman game built in Python as part of the **CodeAlpha Python Programming Internship** (Task 1).

## Features
- Random word chosen from a list of 5 predefined words
- Maximum of 6 incorrect guesses
- Basic console input/output (no graphics or audio)
- Input validation (single letters only, repeated guesses are ignored)
- Option to play again

## Concepts Used
`random`, `while loop`, `if-else`, `strings`, `lists`

## How to Run
1. Install Python 3.
2. Clone this repository:
   ```
   git clone https://github.com/<your-username>/CodeAlpha_Hangman.git
   cd CodeAlpha_Hangman
   ```
3. Run the game:
   ```
   python hangman.py
   ```
